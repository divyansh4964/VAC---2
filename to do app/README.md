# My Tasks — To-do App

A responsive React to-do app built with Vite. Add, edit, complete, delete, and filter tasks; task data is saved in your browser.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. Open a terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

3. Open the local URL printed in the terminal (usually `http://localhost:5173`).

## Features

- Add, edit, complete, and delete tasks
- Filter by all, active, or completed tasks
- Summary cards and a live completion progress bar
- Saves tasks in browser local storage
- Responsive layout for desktop and mobile
